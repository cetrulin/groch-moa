# Parameter Tuning & Experiment Scripts (SLURM / Bash)

This folder contains the bash and SLURM scripts used to run parameter tuning and benchmark experiments for GroCH in an HPC cluster.

> **Note on `meta.NA` vs `meta.GroCH`:**  
> These legacy experiment scripts reference `meta.NA` (the original name of GroCH used in tags `v0.1-moa2017.06` through `v2.0.0-moa2024.07`).  
> On `main` (`v3.0.0-capymoa`+), `NA` was renamed to `GroCH` (`meta.GroCH`). Either check out tag `v1.0.0-moa2017.06` / `v2.0.0-moa2024.07` to run these scripts verbatim, or replace `meta.NA` with `meta.GroCH`.
